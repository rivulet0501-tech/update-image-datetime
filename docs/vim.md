# Vim/Vi 删除操作速查手册

> 本文档聚焦于"查看并删除当前光标所在行之前的内容"，涵盖行内删除、多行删除、可视模式确认、撤销/重做及常见坑。

---

## 1. 删除光标到行首（行内）

| 命令 | 说明 |
|------|------|
| `d0` | 删除从光标**前一个字符**到**行首**（不含光标所在字符） |
| `d^` | 删除从光标**前一个字符**到**第一个非空白字符**（不含光标所在字符） |
| `D` | 删除从光标**当前字符**到**行尾**（注意：方向相反，此处仅供对比） |

> **`d0` 与 `d^` 的区别**：若行首有缩进（空格/Tab），`d0` 会把缩进也删掉，`d^` 只删到第一个非空字符处。

### 示例

假设光标在 `|` 处：

```
    Hello, World!
         |
```

- `d0` 结果：`World!`（行首到光标前全部删除，包含缩进）
- `d^` 结果：`World!`（若光标正好在第一个非空字符前则与 `d0` 相同；否则保留缩进）

## 2. 删除当前行之前的所有行（到文件开头）

### 2.1 `dgg`

在普通模式下，将光标所在行**之上的所有行**连同当前行一并删除（移动到文件第 1 行并删除到当前行）。

```
dgg
```

> **注意**：`dgg` 删除的是**第 1 行到当前行**（含当前行）。若只想删除当前行之前的行，先 `k`（上移一行）再 `dgg`，或使用下面的命令行方式。

### 2.2 `:1,.d`（Ex 命令）

```vim
:1,.d
```

- `1` 表示第 1 行，`.` 表示当前行，`d` 表示删除。
- 等价于删除**第 1 行到当前行**（含当前行）。
- 若只删当前行之前（不含当前行）：

```vim
:1,.−1d
```

### 2.3 带寄存器：先复制再删除

如果想在删除前把内容保存到寄存器（防止误删），可以先复制到具名寄存器 `a`，再删除：

```vim
" 先把第 1 行到当前行复制到寄存器 a
"aygg

" 再删除第 1 行到当前行
dgg
```

或用 Ex 命令版本：

```vim
:1,.y a    " 复制到寄存器 a
:1,.d      " 再删除
```

之后可用 `"ap` 粘贴寄存器 `a` 中的内容。

## 3. 查看/确认将删除的内容（可视模式）

在正式删除前，建议先用**可视模式**高亮选中，确认范围无误后再删除。

| 命令 | 可视模式类型 | 说明 |
|------|------------|------|
| `v` | 字符可视 | 逐字符选择 |
| `V` | 行可视 | 逐行选择（常用） |
| `Ctrl+v` | 块可视 | 矩形块选择 |

### 操作步骤

1. 在文件开头按 `gg` 跳到第 1 行。
2. 按 `V` 进入行可视模式。
3. 用 `j`/`↓` 向下选中到目标行（或直接 `G` 选到末尾）。
4. 确认高亮区域无误后，按 `d` 删除。

也可先用 `V` 在当前位置开始选，然后用 `gg` 扩展到文件开头：

```
V       ← 进入行可视模式
gg      ← 向上扩展选区到第 1 行
d       ← 删除选中内容
```

确认完毕再删除可使用 Ex 范围命令：

```vim
:'<,'>d
```

（`'<` 和 `'>` 是可视模式自动标记的起止行。）

## 4. 撤销与重做

| 命令 | 说明 |
|------|------|
| `u` | **撤销**上一步操作（可多次连按） |
| `Ctrl+r` | **重做**（撤销的反向操作） |
| `U` | 撤销对**当前行**的所有修改（注意与 `u` 的区别） |

> **常见坑**：`U`（大写）只能撤销当前行，且本身也会被计入撤销栈，多次使用容易混乱，建议优先用小写 `u`。

## 5. 示例与常见坑

### 示例 1：删除光标所在行到行首（不含缩进）

```
d^
```

### 示例 2：删除文件开头到当前行（含当前行），并保留副本

```vim
"adgg      ← 复制到寄存器 a 并删除
"ap        ← 如需恢复，粘贴寄存器 a
```

### 示例 3：用可视模式安全删除前 5 行

```
gg         ← 跳到第 1 行
V          ← 进入行可视
4j         ← 向下选中 4 行（共 5 行）
d          ← 确认无误后删除
```

### 常见坑

| 坑 | 说明 | 应对方法 |
|----|------|---------|
| `dgg` 连同当前行一起删 | `dgg` = 从第 1 行删到**当前行**（含） | 若不想删当前行，先 `k` 再 `dgg` |
| `D` 方向是向右 | `D` 删除光标到**行尾**，不是行首 | 向行首删用 `d0` 或 `d^` |
| 删除后默认存入无名寄存器 | 下次 `d` 会覆盖 | 用具名寄存器 `"a` 保存重要内容 |
| 撤销层数有限 | 默认 `undolevels=1000` | 可在 `.vimrc` 中调大：`set undolevels=5000` |
| `:1,.d` 含当前行 | 若只删前面的行 | 用 `:1,.−1d`（减 1） |
